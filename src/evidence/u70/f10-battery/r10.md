1. **Verdict Logic Flaw:** The proposal defines "PARTIAL" as exactly one bar being met. However, the primary outcome requires *both* the probe $\ge 0.70$ AND the gap $\ge 0.05$ to be met for a FIXED verdict. If only one is met, it is PARTIAL. This creates a binary dependency where the "gap" (a measure of behavior) can trigger a PARTIAL verdict even if the "probe" (a measure of competence) fails completely. This smuggles a "partial success" into the results without ensuring the baseline competence of the ensemble.

2. **M-Justification Gap:** Claiming $M=5$ is for "granularity" to see 3-2 splits is a descriptive goal, not a structural justification for the ensemble size. Without a prior power analysis or a fixed ratio of disagreement to signal, $M=5$ is an arbitrary choice masquerading as a requirement.
