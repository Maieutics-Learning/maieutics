# F5 barrage r2 (verbatim)

1. **Comparability Break**: The proposal defines the primary unit as the per-seed mean over $k=0..2$. However, the "Paired Primary" is defined as $\text{mean}(F5) - F4$. This is a mathematical mismatch. $F4$ was a single-init run ($k=0$). By averaging $k=0, 1, 2$ in $F5$, you are no longer comparing the same unit of analysis (single init vs. mean of three). If $k=1$ and $k=2$ are significantly worse than $k=0$ (the "lottery" effect), the $\text{mean}(F5)$ will be lower than $F4$ even if the model is stable, creating a false signal of degradation.

2. **Verdict-Logic Leak**: The "Lottery Ceiling" is listed as descriptive, but the "Verdict" section allows a `max-pass + mean-fail` to be filed as `LOTTERY-CEILING`. This converts a descriptive metric into a categorical verdict, violating the "descriptive-only" constraint.
