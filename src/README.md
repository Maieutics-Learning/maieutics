# Teaching Small Models to Learn

Long-term project: build our own AI inspired by Geiping et al. **arXiv:2502.05171**
(Huginn 0125) — recurrent-depth latent reasoning ("thinking without tokens").

Start here: `src/CHATLOG.md` (session log — decisions + measurements, newest last).

## What the paper did (Sec 3–7)
- Architecture triplet `(prelude, core, coda)`: `e = P(x)`, loop `s(i) = R(e, s(i-1))` from random `s(0)`, decode `p = C(s(r))`. Input `e` re-injected every step via concat adapter.
- Stable at scale via sandwich RMSNorm, RoPE base 50000, gated SiLU MLP, truncated backprop, random `r` per forward pass, standard LM loss (no CoT data).
- Test-time: unroll further than training. 3.5B / 800B tokens → up to ~50B-equivalent on reasoning. Math/reasoning gains a lot, facts flatline.
- Sec 7: latent trajectories orbit on numerical problems, settle fast on easy facts.
- Links: paper https://arxiv.org/abs/2502.05171, model https://huggingface.co/tomg-group-umd/huginn-0125, code https://github.com/seal-rg/recurrent-pretraining. Baselines: CoT https://arxiv.org/abs/2201.11903, s1 https://arxiv.org/abs/2501.19393. Attention-free direction: Grassmann flows https://arxiv.org/abs/2512.19428 (Dec 2025, small-scale — spec for Phase 2d in CHATLOG).

## Phase 2b (built — running-state core + process supervision)
Answers "why can't we chunk longer strings?": the pooled net learned one
glance, not a procedure. `SeqModel` reuses one gated cell over POSITIONS (fresh
input each step) then DEPTH (sequence summary re-injected, paper-style); a gate
lets the state carry a bit. Per-step running-parity labels (process supervision
— the CoT analogue: outcome-only supervision memorizes, step supervision teaches
the rule) hold every position to the running answer.
- parity, train len ≤6: 100% in-dist, 100% len-10 at every depth, 100% len-20
  (3x train max) — generalization by construction, ~46s on CPU.
- UI verdict logic separates "solved at r=1, depth unneeded" (parity-R) from
  the mod-add depth curve — both reported honestly.
- adapt to len-7: zero-shot 100%, holds 100% vs scratch 57% — full transfer.
Gating + dense-label gradients grad-checked exact (1e-9).

## Phase 2c (built — single-head attention core + selection supervision)
Answers "what is attention FOR?": fixed-size states must COMPRESS bindings,
attention can LOOK BACK. `AttnModel` unrolls over positions; each step queries
a causal dot-product memory over past position STATES (keys/values, like the
paper's recurrent block holding a self-attention layer), gates the retrieved
vector into the running state. Depth steps re-query the full memory. Task is
assoc-recall: `[k1,v1,...,kp,vp,q,Q]` → value bound to q (keys 0..3, values
4..7); train 1..3 pairs, test 4 (hard) and 6 (2x max).
- Two process-supervision signals, same theme as 2b: BIND labels (at each value
  position, predict the key — the previous-token half of the induction
  circuit) + SELECTION labels (at the final step, put weight on the value
  position of the queried key — `-log w[target]` straight through the softmax).
  Outcome-only training memorizes (hard ~0.5); the two aux signals install the
  lookup circuit instead.
- assoc-recall, UI recipe (h48/d16, 1200 steps, ~60s): 100% one-pair, 99.5%
  in-dist, hard (4 pairs) ~0.96 FLAT across r=1..16 — lookup, not depth.
  6 pairs: ~0.57 (capacity limit past 2x, honest).
- Gated-RNN baseline, same data + bind labels, no attention: in-dist 0.84,
  hard ~0.59, and ~5% on held-out (key,value) combos vs attention's ~97% —
  the RNN memorizes the training distribution's correlations; attention learns
  the rule. That gap is the whole point of 2c.
- adapt to 3..4 pairs: zero-shot ~98% → 100% vs scratch ~58% in 60 steps.
- Attention grads (value path, selection path, gate-through-retrieval) all
  grad-checked exact (~1e-10); `quickAttnTest` guards the pipeline (~8s).
