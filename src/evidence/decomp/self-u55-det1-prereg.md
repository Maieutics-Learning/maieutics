# U55-DET1 prereg v1.0 — detector measurement (first step of the P1 program, unlocks E-NE1/E-ACh1)

**Track:** U55-DET1 (E2c follow-up + E-UNC1 split, order-of-battle step 2). **Cover:** user 2026-11-26 "Go ahead and lets do one and 2" (+ heavy multi-round batteries for the detector track) = prereg + batteries (≥2 rounds) + driver. NO probe/train compute until fresh countersign on the final version. NO PUSH without separate explicit order.
**Question:** do non-degenerate, dissociable surprise signals exist in the frozen substrate — a cue-reliability tracker that sees noise-but-not-switches, and a switch detector that sees switches-but-not-noise?

## Why measurement-first (no trains)
E2c SURPRISE-FAIL (mFinal 0/0/0, taken 0 rows, ORDER 0/3): binary agreement never varies (trunk vote == miner vote on low-cue → surprise 0 always) and the fixed baseline drives m to floor. Building another learned detector on the same signal repeats the failure. U50's lesson: outcome without adapt-speed separation keeps both accounts alive — so first prove the *signals* exist (frozen trunk, read-only probes), then build consumers (E-NE1 triggered gain) that must move both outcome AND adapt-speed. No stack surgery; stack pin 258d2f06.

## Design (frozen trunk, read-only)
- **Trunk:** U33 canonical (s0–s2, frozen byte-exact, PIN verified per probe run). Nothing trains. Ever.
- **Diet cells 2×2** (probe-only streams, N=200 rows each): CUE {CLEAN (standard u34 slots) vs NOISY (rows with qk∈{4,5} get label y re-randomized — permanently unreliable cues = expected uncertainty)} × REGIME {STAT (fixed hot set) vs ROT (quarter-rotating hot set à la U50 = unexpected uncertainty)}. Exact stream construction filed in Wave 0 (same code path as training rows, different RNG streams; no probe flag exists in the substrate).
- **D-cue (reliability tracker):** per-slot EMA error e_s ← 0.9·e_s + 0.1·1[pred≠y] over the stream; response = mean(e over noisy slots) − mean(e over clean slots). Must be large in NOISY cells, ~0 in CLEAN cells.
- **D-switch (switch detector):** block error over trailing 50 rows minus trailing 200 rows; response = max value within 25 rows after a quarter boundary (ROT) vs same statistic at matched positions (STAT). Must spike in ROT, stay flat in STAT.
- **Streams (the N=20 rule in measurement form):** 20 probe streams per diet cell per trunk (3 trunks × 4 cells × 20 = 240 probe runs). Per-trunk verdict from the 20-stream mean ± SE. Quorum 2/3 trunks. (Training seeds stay R=3 until E-NE1, which is preregged separately with 20 train seeds — stated here so the N=20 order is visibly split across its two forms.)

## Bars (quorum 2/3 trunks unless noted)
- DET-NONDEGEN: both detectors fire on target (D-cue gap > 0 AND D-switch spike > 0 on all 3 trunks — neither sits at ~0; the E2c failure mode fails here by construction).
- DET-DISSOCIATE (double dissociation, first-pass margins open to battery revision): D-cue NOISY-minus-CLEAN gap ≥ +0.15 in both regimes AND ≤ +0.05 cross-check (gap must not grow in ROT vs STAT by more than 0.05 — it tracks noise, not switches); D-switch ROT spike ≥ +0.10 AND STAT spike ≤ +0.05. Four sub-conditions, need 3/4 at quorum.
- DET-INDEPEND (P2b pin): |corr(D-cue response, D-switch response)| < 0.7 across the 80 streams per trunk (they are not the same signal); loss-derivative charge structurally void (frozen trunk, no training, no loss exists at probe time — stated, not assumed).
- DET-PIN: stack 258d2f06 in every ledger + trunk params byte-identical to U33 canon (HALT on drift).
- Diagnostics filed regardless: full per-stream responses, per-trunk means/SEs, inter-detector r, quarter-boundary spike traces.

## Waves (all read-only; nothing trains)
- Wave 0: driver load-check + stream reproducibility (same stream → identical rows) + formula dry-run on 1 stream per cell (values filed, thresholds NOT retuned — dry-run is a crash test, margins stay as preregged unless the battery moved them first).
- Wave 1: 240 probe runs COMPLETE-gated.
- Wave 2: verdict.

## Verdicts
- DET-HEALTHY: NONDEGEN + DISSOCIATE (3/4) + INDEPEND at quorum → licenses E-NE1 (triggered gain, must move outcome AND adapt-speed) and unblocks E-ACh1 scheduling design.
- DET-ENTANGLED: detectors fire but dissociation fails → the split buys nothing; single-scalar design stands; E-NE1 may NOT use two detectors (one scalar or nothing).
- DET-COLLAPSED: either detector ~0 → back to design (new signal source required; do not build consumers).
- PIN-FAIL guard as filed.

## v1.1 pins (battery R1 10x NEEDS-PATCH unanimous → doc-only, no compute exists)
- M1 cross-check operator: gap_R = mean_streams(Dcue_NOISY,R − Dcue_CLEAN,R) per regime R; cross = |gap_ROT − gap_STAT| ≤ 0.05 (D-cue tracks noise iff the NOISY−CLEAN gap is regime-invariant).
- M2 NONDEGEN epsilon: target responses must exceed +0.05 (D-cue gap in NOISY cells; D-switch spike in ROT cells); ~0 ≡ within [−0.05,+0.05]; in-between values are weak (fail HEALTHY, route to ENTANGLED/COLLAPSED per table).
- M3 stream length N=400 rows (was 200 — trailing-200 baseline needs room); quarters every 100 rows (3 boundaries/stream); sliding per-row trailing windows; spike window 25 rows post-boundary; thresholds unchanged (ROT ≥ +0.10, STAT ≤ +0.05).
- M4 relabel: in NOISY cells, rows with qk∈{4,5} get y replaced (p=0.5) by an independent uniform random class (permanently unreliable cues).
- M5 hot sets: STAT puts 0.7 mass on {0,1}; ROT puts 0.7 mass on the rotating pair {0,1}→{2,3}→{4,5}→{6,7} per quarter; remaining 0.3 uniform over 8 slots. Overlap of noisy slots {4,5} with ROT quarter 3 is intentional and subtracted out: the gap is NOISY−CLEAN within-regime, so shared quarter effects cancel.
- M6 P2b replacement (R1 6x: "void by definition" is tautological): INDEPEND = |r(Dcue-responses, Dswitch-responses)| < 0.7 across the 80 streams/trunk AND all dissociation margins still hold after regressing out per-stream mean error (partialled gaps meet the same thresholds; else ENTANGLED). The "structurally void" phrasing is retracted.
- M7 quorum stats: per-trunk verdicts from 20-stream means; SE = SD/√20 filed as precision diagnostic (not a decision boundary); no pooling across trunks (a failed trunk is 1/3, period); 2/3 of 3 is decisive (no ties possible). Power honesty flag: if 2×SE > the applicable margin on ≥2 trunks, file UNDERPOWERED alongside (never flips) the verdict.
- M8 filters by design: D-cue EMA α=0.9 (~10-row memory, slow level) vs D-switch 50-vs-200 sliding (~150-row baseline, change). Different time constants on purpose (level vs change); both parameters frozen here.

## v1.2 pins (battery R2 10x NEEDS-PATCH → doc-only, no compute exists)

- N3 no-cross-boundary windows (R2 2x: trailing-200 spans 2 boundaries): baseline and current windows reset at filed boundaries — only in-quarter rows enter either window; D-switch evaluated only where ≥50 in-quarter rows exist (first 50 rows post-boundary excluded from maxima — detection latency ≤75 rows is then the tested claim; file realized latency as diagnostic).
