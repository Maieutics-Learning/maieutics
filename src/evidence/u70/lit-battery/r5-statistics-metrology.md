# Lit-lessons scout 5 (statistics/metrology)

1. Overclaimed: B2's operationalization of "what counts as a change." Mapping hippocampal remapping (a biological process) to specific U70 metrics (delay median 2, FA 0.7/100) is a category error. The metrics describe *performance* of a detector, not the *mechanism* of inference.

2. Kill-shot: A control run varying the `p_sw` (switch probability) and `dwell` time. If the "operationalization" is valid, the FA rate should scale linearly with the noise floor of the cue reliability ($\rho$), not just stay below an arbitrary $0.7/100$ threshold. If FA is independent of cue reliability, the metric is a measure of the oracle's precision, not a biological proxy for hidden-state inference. Downgrade B2 from "operationalization" to "benchmarking."
