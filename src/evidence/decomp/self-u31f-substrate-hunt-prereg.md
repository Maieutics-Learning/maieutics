## Design

Frozen (both stages): retrieval S/C/INH/HF (U28 per seed) + trunk Mf (W6, never stepped) + U31b R2MON gate (selection only, weights from d-newai-self-u31b-r2mon-s{seed}-800st.json; reused across regimes — see limitation L1) + miner (floors only).
Trainable: trunk COPY Mc per (regime, arm, seed), init bit-exact from W6 (copy-fidelity checked). Only Mc stepped. Retrieval never sees Mc (structural no-touch, U31e-identical).

Task base (U31e-identical): round-2 composition. Input x2m=[9x5,qk,k,vhat_f,8] with vhat_f from FROZEN forced pipeline (deployment-conditioned); label e.y. Loss CE(inMeanLogits(fw2), e.y), Mc params only, Adam lr5e-3, clip 1.0, B=16, fixedMasks (91000+seed family). Diet per batch: 8 hard + 8 std (std = shift rows, round-2 with frozen-std vhat=argmax(hv+read)).

Regimes (Stage A candidates; each = one recipe change vs U31e base; all keep x2m shape so the frozen gate applies without retraining):
- R1 LESIONED-VALUE: break vhat_f on purpose (the U31/U31c ceiling, attacked). vhat_f replaced by second-best of ensBase (argmax excluding top1); ties -> top1+1 mod 4. Gate sees the same x2m layout (lesioned vhat one-hot in slots 16-19). Hypothesis: value failures become real, composition must compensate; random may fail because the input lies.
- R2 INTERFERENCE-HEAVY: hard pool filtered to high-interference rows only. Filter (label-free, frozen pipeline): keep adapt candidate iff >=2 support pairs share the query key's key-id OR the top-2 readLogits margin < 0.5 (crowded neighbourhood). Rejection-sample to fill diets (cap 40 tries, fallback counted). Hypothesis: crowded bindings break the single-hop shortcut.
- R3 OOD-BINDINGS (held-out combos): round-2 train pool restricted to allowed-only (key,value) combos (diag never seen in Mc training); eval on diag-target rows (killHd-style: DIAG target + ALLOWED distractors; killDa reported as context). Miner-mined 66300 base, combo-membership from episode generator metadata. Hypothesis: memorized-pair circuits fail, addressable lookup required (E1b/F2 lesson ported to round-2).
- R4 TWO-HOP: label changed to y2 = (e.y + vhat_true) mod 4 where vhat_true = argmax of frozen ensBase (label construction uses the frozen pipeline, no human labels). Input x2m unchanged (carries vhat_f one-hot). Hypothesis: single-hop retrieve-then-output shortcut insufficient; must compose retrieved value with second mapping. Random diets that memorize y fail; selection of rows where vhat_f != vhat_true (gate-predicted-fail rows) may teach the hop.
- (Considered, NOT run: disagreement-dense slice as 5th regime — subsumed: R2's margin filter + gate-p pre-filter in Stage B cover it without a new recipe. Disagreement-OOD interaction is a follow-up, not a 5th arm.)

Stage A (screen, rand-only, cheap): per (regime x seed): 1 rand train (400st, U31e-identical otherwise: 8 hard + 8 std, uniform adapt episodes from randRng 93500+seed / slots 94500+seed, regime recipe applied) + 1 rand eval (N=1000 paired held-out, regime-specific eval rows per below) + 1 frozen reference (Mc-none zero-step copy, determinism check). Total 12T + 12E (4 regs x 3 seeds). NO sel/neg arms in Stage A (selection untestable until rand fails).
- Eval rows per regime (mined ONCE per seed, deterministic base -> identical row sets across future arms, paired): R1 lesioned-hard (66300 rows, lesioned vhat_f at eval too — deployment-conditioned); R2 interference-hard (66300 rows passing the interference filter); R3 diag-target rows (held-out combos) + allowed-target rows (context); R4 two-hop rows (y2 labels, same 66300 ids).
- Stage-A SURVIVOR gate (pre-registered, per regime, quorum 2/3 over seeds): rand hardY <= 0.60 AND rand-minus-frozen <= +0.05. Rationale: U31e rand reached 0.62-0.93 with lifts +0.08/+0.21 — survivors must be regimes where 400st of random pressure does NOT lift. Regimes failing the gate are DEAD (filed, not promoted). At most 2 survivors advance (if >2 pass, advance the 2 with lowest rand hardY; tie -> lowest rand-minus-frozen).
- If ZERO regimes survive: verdict SUBSTRATE-ABSENT (not VOID — the hunt ran, the ground is bare at this scale/recipes). No Stage B.

Stage B (selection test, survivors only): per (survivor regime x seed): 4 arms e-sel / e-neg / e-rand / e-none, U31e-identical diets (sel: keep iff gate p<0.5, 20-try cap + fallback counting, bases 93400/94400; neg: keep iff p>=0.5, bases 93600/94600, killer; rand: uniform 93500/94500; none: zero-step copy), 800st, 8 hard + 8 std. Eval N=1000 paired (same row sets as Stage A for that regime/seed). Max 2 regimes x 4 arms x 3 seeds = 24T + 24E; typical 1 regime = 12T + 12E. COMPLETE-gated.
- SELECTION-VOID tripwire (per regime, before any Stage-B train): 1000 adapt candidates/seed with regime recipe, report P(p<0.5). If < 0.10 ANY seed: that seed's e-sel arm VOID (train + eval VOID ledgers filed; neg/rand/none unaffected). 2/3 VOID -> regime SELECTION-VOID, no Stage-B trains for that regime.
- Probes (regime survivors): frozen-state gist-style transit curve dist1/dist7/dist14 (reported, never gated): want graded decay with head < probe (info in transit the head can't use = learnable substrate signature). Flat-chance probes filed as substrate-negative evidence.
- Verdict per survivor regime: d-newai-self-u31f-{regime}-verdict.json; plus overall d-newai-self-u31f-verdict.json (SUBSTRATE-FOUND / TRAINS-BUT-BLIND / COMPOSITION-UNLEARNABLE / SELECTION-VOID / SUBSTRATE-ABSENT).

Limitations (pre-registered, not post-hoc excuses):
- L1 gate transfer: U31b gate trained on base-distribution x2. R1/R2/R4 shift its input distribution; p<0.5 calibration may drift (s0 precedent: 0.096 base). The tripwire + fallback/dilution reporting (P1b) contain this; gate retraining is OUT OF SCOPE (would confound selection with new learning).
- L2 R3 combo metadata depends on episode generator exposing pair membership; if unavailable, R3 degrades to slot-shifted OOD (shift rows with held-out qk ids) — filed as deviation, same bars.
- L3 400st Stage-A vs 800st Stage-B: a regime where rand needs >400st to lift is a slow-substrate false positive. Contained: Stage-B rand runs 800st; a survivor where 800st rand lifts (breaks the +0.05 gate at 800st) is demoted to TRAINS-BUT-BLIND, not FOUND.

## Paper predictions vs bench predictions (divergence-WHY owed)
- Appetite/self-direction (bench): gate-selected diets lift where random diets fail, BECAUSE the gate selects learnable rows (predicted-fail = learnable, U31e guardrail reading) rather than merely avoiding unlearnable ones. WHY owed if: no Stage-A survivor (hunt premise wrong at this scale) / survivors but sel<=rand (U31e repeats on harder ground — selection still guardrail) / neg>=sel (demotion: gate is a random sampler).
- Hard-mining literature (imported, scoped): mining helps in-distribution/boundary, no OOD guarantee (pre-step check). WHY owed if R3 (the OOD regime) is the ONLY survivor but sel still fails — matches literature, bounds the mission claim to in-distribution composition.
- Norman #5 / Henson (imported, scoped): selection helps where the module is weak AND the failure signal is readable. U31e showed weak-module (round-2) + readable-gate still = guardrail. WHY owed if R1 (lesioned value) survivors show sel-rescue: readability restored by lesioning is the difference vs U31c.

## Bars (quorum 2/3 unless noted; N=1000 paired => per-seed SE~=0.0224; LIFT +0.05 ~= 2.23 sigma p~=0.013/seed, quorum joint ~=0.0005; SEL +0.03 ~= 1.34 sigma p~=0.09/seed, quorum joint ~=0.023 — computed this session via execute_js, filed)
- U31f-SCREEN (Stage A, per regime): survivor iff hardY_rand <= 0.60 AND hardY_rand minus hardY_frozen <= +0.05, 2/3 seeds. (Both halves required: absolute failure + no lift.)
- U31f-LIFT (Stage B, per survivor): hardY_sel minus hardY_frozen >= +0.05 2/3 (sel-only seeds count if VOID elsewhere per D0-style adjustment, pre-registered).
- U31f-SEL (Stage B, per survivor, THE self-direction claim): hardY_sel minus hardY_rand >= +0.03 2/3 (paired identical row sets).
- U31f-NEG-KILLER (demotion with teeth, U31e P1c inherited): if sel-minus-neg < 0 on 2/3 seeds, verdict caps at TRAINS-BUT-BLIND even if SEL holds (gate is a random sampler on this regime).
- U31f-RET: stdTwo_sel >= stdTwo_frozen minus 0.03 3/3 (all arms reported; if sel forgets where rand/neg don't, file overfitting reading — U31e P1d rule).
- U31f-NONE: Mc-none numbers EXACTLY equal frozen 3/3 (copy fidelity + determinism).
- U31f-FROZEN: maxAbsDrift of Mf/S/C/INH/HF/gate == 0.0 3/3 (nothing but Mc moved).
- U31f-FRESH: battery health 4/4.
- U31f-DIVERSITY (reporting, never gated): per-arm mineTries/kept/fallback/mean-tries-per-keep + dilution rate in every train ledger.
- Verdicts per survivor: SUBSTRATE-FOUND (SCREEN survivor + LIFT + SEL hold + NEG-KILLER clears) / TRAINS-BUT-BLIND (LIFT holds, SEL fails) / COMPOSITION-UNLEARNABLE (no LIFT in sel or rand at 800st) / SELECTION-VOID (tripwire) . Overall: SUBSTRATE-FOUND if ANY survivor regime FOUND (named); else SUBSTRATE-ABSENT (no SCREEN survivor) or best-survivor verdict carried with regime label.
