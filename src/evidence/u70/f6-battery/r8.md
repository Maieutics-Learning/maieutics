# F6 barrage r8 (verbatim)

1. **Gradient Leakage/Redundancy**: The "soft teacher" reading $q$ is mathematically a proxy for increasing `ctxw`. Since $q$ is the distribution from which $z$ is sampled, penalizing $q$ directly is functionally identical to penalizing $z$ via a higher weight. It is a disguised sweep of the same hyperparameter.

2. **Instability Risk**: Adding a new MLP head with its own Adam state, initialized randomly, introduces a stochastic variable into a "frozen" base. This breaks the "F4 Exact" comparability; you are no longer testing a mechanism, but a new initialization's interaction with the encoder.

3. **Evaluation Gap**: If the soft teacher succeeds, it may do so by smoothing the latent space, which could artificially inflate the detached probe's accuracy without solving the "flip" mechanism. The probe remains detached, but the teacher is now actively shaping the manifold the probe measures.
