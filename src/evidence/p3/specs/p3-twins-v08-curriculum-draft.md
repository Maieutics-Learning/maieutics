# Twins v0.8 CURRICULUM DRAFT v2 (2026-11-18) — UNCOUNTERSIGNED, no compute
User's principle (filed as the binding constraint): NO brain ever receives
anything but raw lines during training. No soft targets, no hard labels, no
distillation — not tutor, not student. Anything that knows the rule is a
thermometer, never a teacher. Supersedes the v1 curriculum draft (tutor
distilled N-9601 = us handing it the rule) and the committee-filter draft.

## What learns, from what
- Tutor = MOUTH (fresh 19-way attn, seeds 9840/9841/9842). Learns ONLY by
  next-token prediction on raw lines (unsupervised — the v0.6 trainMouth
  recipe, ≤800 steps, batch 8, lr 5e-3). Nothing else ever enters it.
- Student = MOUTH (fresh 19-way attn, seeds 9850/9851/9852). Learns ONLY by
  next-token prediction on tutor-WRITTEN raw lines. Nothing else ever enters it.
- "Tutor writes class" is now LITERAL: ancestral generation (prefix-3 +
  T=1.0, rng outside loop), 100 lines per class, seeds 9871/9872 (+pair
  offset filed below).
- Thermometers (grade, never teach): frozen N-9601 (random ear) and frozen
  d1a (educated ear). They grade generated lines to measure dialect
  similarity. They train nothing and nothing distills them. This answers
  "E and N through the experiment": BOTH run as instruments on every
  generated set — no E-rule arm, no N-rule arm, no teacher arms at all.

## Pools (raw lines only, class/test disjoint by construction)
- EASY: structured-recon Markov-repeat p=0.35, seed 9770, 600 lines:
  first 500 = tutor-train, last 100 = easy TEST (raw held-out).
- HARD: uniform noise, seed 9810, 600 lines: first 500 = tutor-train,
  last 100 = hard TEST (raw held-out).
- Class lines are GENERATED by the tutor (never pool lines), so class/test
  overlap is impossible by construction.

## Frozen-test matrix (user's rule: frozen, before AND after every class)
At each frozen stage the mouth takes BOTH raw held-out loss tests AND
generates 100 lines (seeds 9880+stage, filed) for thermometer grading:
- Stage S0 (init): easy-test loss, hard-test loss (before everything).
- Tutor-E (tutor after 500 easy): easy/hard loss (tutor gate: easy-test
  loss must beat its own init loss by ≥0.20 nats, else HALT pair) +
  writes CLASS 1 (100 lines, seed 9871+pair).
- Stage S1 (student after class 1): easy-test loss (CLAIM 1), hard-test
  loss (transfer, descriptive) + generates for thermometers.
- Tutor-H (tutor continued on 500 hard): easy/hard loss (gate: hard-test
  loss beats tutor's S0-equivalent by ≥0.20 nats, else HALT) + writes
  CLASS 2 (seed 9872+pair).
- Stage S2 (student after class 2): hard-test loss (CLAIM 2), easy-test
  loss (retention = S2-easy vs S1-easy, descriptive) + generates.
- Blinds (fresh 19-way inits 9860/9861/9862): both test losses (static
  reference — untrained, so one measurement each) + generate 100 lines
  (seed 9889+pair) for thermometer baselines.

## Bars (per pair; quorum 2/3 over 3 pairs)
- CLAIM 1 (easy teaching works): S1 easy-loss ≤ S0 easy-loss − 0.20 nats.
- CLAIM 2 (hard teaching works): S2 hard-loss ≤ S1 hard-loss − 0.20 nats
  (improvement OVER the transferred level — the class must add beyond
  transfer, filed).
- DIALECT (thermometer, N-9601 AND d1a reported separately):
  agree(tutor-written, student-written) − agree(tutor-written,
  blind-written) ≥ 0.15 per stage (U1-shaped gap; per-position modal
  agreement on a shared 200-line pool, seed 9771, same as v0.7 U1).
- Descriptive: transfer (S1-hard vs S0-hard), retention (S2-easy vs S1-easy),
  tutor's own easy/hard curves, blind losses.
- W (kills mouth-curriculum line): tutor gates pass (tutor DID learn raw) but
  both claims fail on ≥2 pairs → dialect doesn't transmit by imitation;
  close mouth line, keep ear-thermometer findings.

## Cost / order
Per pair: tutor 800 + student 800 + 800 full-mouth steps (~15 min) +
forwards. 3 pairs ≈ 45 min. Resume-safe ledgers (scratch/p3-curr-*.json).
