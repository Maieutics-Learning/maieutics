## G

**Selection:** Candidate (a) frozen tutor-as-scorer input search.
**Justification:** Maintains the "no feedback" constraint by treating the tutor as a static oracle for search rather than training a new parameter-dependent head.

**1. SPEC**
1. **Input Space:** $\mathcal{X}$ defined by vocab19 and length-bands from P2.
2. **Search Algorithm:**
   - Initialize seed string $s \in \mathcal{X}$.
   - Perturb $s$ via Gibbs token mutations (random replacement based on $\text{vocab19}$ distribution).
   - Evaluate candidate $s'$ using frozen tutor: $score = \text{softmax}(\text{logits})[\text{target\_class}]$.
   - Iterate until $score > \text{threshold}$ (e.g., 0.90) or max iterations reached.
3. **Filtering Gates:**
   - **Entropy Gate:** $\text{Entropy}(\text{logits}) \ge 1.0$ bit.
   - **Novelty Filter:** $s' \notin \{\text{previously generated set}\}$.
4. **Round-Trip Validation:**
   - Feed generated $s'$ to a blind (separate) instance of the frozen tutor.
   - **Success:** $\text{argmax}(\text{logits}) == \text{target\_class}$ with probability $\ge 0.50$ (where $0.25$ is the random baseline for 4 classes).

**2. OPEN QUESTIONS**

2. What is the maximum iteration count per generated line before failure is declared?
3. Define the "blind re-label" environment: is this a separate seed of the same model or a different architectural twin?

## D

1. SPEC:
**Diagnosis Logic (P2 Step 5)**
For each item $i$ where $\text{TutorLabel}_i \neq \text{StudentLabel}_i$:

1. **DEGENERATE Check**: 
   - If $\text{TutorTop1Conf}_i < 0.50$ OR $\text{TutorEntropy}_i < 1.0 \rightarrow$ Label **VOID**. 
   - Action: Discard from failure analysis.

2. **TRANSMISSION-LOSS Check**:
   - If $\text{TutorTop1Conf}_i \geq 0.70$ AND $\text{StudentLabel}_i \neq \text{TutorLabel}_i$:
     - Check for clustering: If $\text{Count}(\text{StudentLabel} = X) \geq 2 \times (\text{TotalItems} / \text{NumClasses})$ OR (ItemLength $\in$ Longs AND $\text{StudentMiss} = \text{True}$), label **TRANSMISSION-LOSS**.
     - Action: Trigger re-teach via style knobs (order/selection/signal/pacing).

3. **CAPACITY Check**:
   - If item is a "Short" (per length band) AND $\text{TutorTop1Conf}_i \geq 0.70$ AND item is still missed AFTER style-knob re-teach $\rightarrow$ label **CAPACITY**.
   - Action: Log as student structural limit.

**Worked Example (200 items):**
- Tutor confident on 120 items ($\text{Top1} \geq 0.70$).
- Student agrees on 90 of those.
- 30 items are "Tutor-High/Student-Miss".
- **Analysis**: 10 items are "Longs" (Transmission-Loss); 5 items are "Shorts" missed after re-teach (Capacity); 15 items have $\text{TutorTop1} < 0.50$ (VOID).
- **Result**: 10 Transmission-Loss, 5 Capacity, 15 VOID.
