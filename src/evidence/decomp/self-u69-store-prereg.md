## Design (minimal organ + minimal addresses; matched-param dense control)
- Slow store S: separate params (same cell geometry, own Adam instance lr/10 filed = slow plasticity),
  updated EVERY step on the same loss (own dynamics, not a copy) — a second LEARNER, not a mirror.
  Fast store F (the trunk) reads S via bias: F.cNew += β·read(S) with β=0.25 filed.
  Write gate: S updates only on surprise-gated windows (d > μ+σ trailing — cheaper gate than U65's
  k=3.0; filed) — the slow organ learns at important moments (U67's importance idea, architectural).
- Sparse addresses: key = carry cNew projected by fixed random K=16 addresses (seed-filed); write
  top-1 slot only; read top-1 slot only (competitive, no superposition). Weeks (quarters) land in
  different slots → stop fighting for the same 8 dims (the §7f interference claim, tested).
  Interference diagnostic (no quorum): cross-quarter read overlap (expect <0.25 for routed vs ~1.0
  for dense — file either way).
- Control: dense-shared with MATCHED total params (widen F to equal S+F param count — U35 already
  closed widening as an advantage, so a routed win can't be a param win).
- Diet: U64 rule-switch verbatim (heterogeneous regimes are what routing is FOR). Metrics: outcome
  two + RET + transfer (novel-rule quarters, U64 adapt operator on unseen hot sets — routing should
  transfer where dense interferes).
