# F6 barrage r4 (verbatim)

1. **Gradient Leakage/Contamination:** The "soft teacher" reads the same posterior $q$ that the "detached probe" evaluates via argmax. While the probe is detached from the *graph*, the teacher is not. By optimizing the teacher to track $c$ via $q$, the model may learn to encode $c$ in a way that satisfies the teacher's softmax but remains "invisible" or flipped to the probe's linear read, potentially inflating the gap without solving the underlying representation collapse.

2. **Optimization Divergence:** Adding a $1.0$ weight teacher to an F4-exact base introduces a new, competing gradient source without adjusting the learning rate or adding a warmup. This risks destabilizing the latent space, turning a "lottery" of initialization into a "lottery" of gradient interference, rendering the F6-F4 delta uninterpretable.
