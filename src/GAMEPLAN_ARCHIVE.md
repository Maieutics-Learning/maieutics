## Gameplan (v4 — 2026-11-09; stripped of outdated; scope current)
**Destination:** a smart nursery that faces the open world with no curated list (search, games, type chart, asking humans as sources) and hands the learner a curated stack in the right order. Nursery picks the books — no human gold stack as training input (fixed-human curricula appear only as measurement baselines, never as training input). Learner gets curated list only; open-world + consult budget are NURSERY requirements. Dialect = whatever nursery+learner develop (emergent, judged by teaching utility). Scaffolding = anything that helps the nursery teach (order, codes, hints it invents). Ability not drive: overarching-goal authorship OUT, sub-goals within a prompted goal IN; commitment = compute spent persisting through forks. Grade the NURSERY, never the kid: nursery-taught vs baseline-taught (random / raw-pool / fixed-human-expert) on novel variants; PASS = match-or-close to the expert at similar-or-less time+cost. Spawn-first then consolidate. Memorize-vs-derive labeled per subskill — prescribed memorization (openings, chart facts) is good teaching; only unprescribed parroting that dies held-out counts as failure. Moral code: not a goal, not strived for; if one develops emergently it is not excluded.
**Phase 0 IMMEDIATE — H2 answer-only x3000 control (last bench experiment with OUR hand-built scaffolding):** M4/A1/A0 (+S-only probe) x 8 non-7 seeds, 3000 steps, fair slots, evals killA/killHd/killDa/meanPos + mild-200 proxy. Bars (convenience, not law): ignite = killA≥0.60 with Hd≥0.55 floor else uninterpretable; futility stop ≤2 ignitions per 32 runs. Decides: is hint-dependence a time problem or a teaching problem? Grounds everything below.
**Phase 1 — entropy-sharpening + hint fading:** aux that sharpens addressing (entropy down from 0.73 toward 0.002) + fade schedule 100→50→20→0% hints with negative lures. Pass = hint-free kill holds within 0.1 of hinted.
**Phase 2 — Wave D self-distillation:** evolving (never frozen) hinted M4 tutors hint-free student on failure-recovery traces via skill-mistake bank + answer loss (steal gated-verifier polarity in 2.5); iterate G0→G1→G2. Pass = student killA≥0.60 with zero hints; fail = teaching doesn't transfer (finding, not failure).
**Phase 2.5 — RABBITHOLE HARVEST (immediately after H2/D, user-set):** learn and take code+theory+steps from: SDFT continual on-policy distillation, curriculum-extraction distillation, SGSD skill-conditioned gated distillation + skill-mistake banks, emergent-communication lit + reviews, cultural-evolution/iterated-learning degeneration warnings + recursive-language bootstrapping, AlphaZero/MuZero self-play, OPD collection, teach-themselves (teacher-proposes-problems paid by student hard-gain), THINK-OR-REMEMBER + neuron-level mem/gen split. Output = sandbox ports + theory notes + step recipes upgrading D/curriculum/evo. Novel in mechanism (nursery-as-evolving-codec + spawn-consolidate + learned staircase), not in goal.
**Phase 3 — auto-curriculum (mastery-gated):** order short→long, few→many, familiar→novel; advance iff kill>threshold. Staircase itself becomes a tunable (first thing the nursery learns to write).
**Phase 4 — evo breeds bootstrappers:** fitness = hint-free ignition × compression-to-recall (few active params, sparsity anti-warehousing penalty); genes = S-addressing precision + aux-decay rate + symmetry; holdout gate = novel-token (unseen symbols) zero-shot + shifted-grid probe. Readout genes stay parked.
**Phase 5 — smart nursery (final):** 5.0 emergent-dialect protocol (judged by teaching utility; PCE keeper = useful info per whisper-token; shifted-grid/rotation probe; KL collapse detector tau 0.3; high-PCE + sub-random novel = cheat-code, prune) → 5.1 messy-pool collator v0 (synthetic open world: noisy/dupe/contaminated pool; perplexity+MinHash first filter; nursery filters+orders into curriculum; scored on ignition per collation cost; sleepers assumed to survive filtering — caught by wiggle/rule-change tests downstream) → 5.2 search tool (sandbox fetch+filter+dedup; cite-to-source rule) → 5.3 human consult (source like search, never grader: default teach-it-yourself; paid heuristics/slang/pointers only, VoI-gated, never brute-force verification; no human ever grades; evaluation is automatic; never a blocker) → 5.4 multi-domain bench (assoc + parity + mod-add + tactics-toy harness; cross-domain transfer = gate; dual-pool stress A→B with ΔA≈0 + cross-modal pivot rehearsal) → 5.5 field pilot (chess tactics from books/games; Pokémon later; profiler as hardest open-domain probe) → 5.6 graduation harness (ALL NURSERY-LEVEL: instructional-delta (T×C ratio) ≥1.0 vs each baseline; raw-volume-no-teaching control must fail; wiggle-test + explain-why; rule-change brittleness check; dialect-strip check (re-teach in plain words — collapse = cheat-code); per-subskill memorize-vs-derive labels respected; novel-token, rotation, novel-position/frozen-knight/anti-computer, 16→64 transfer, siren adherence as teacher metrics) → 5.7 final refinement (user-set): exceed fixed-human novel score at lower cost (sparsity↑ + generalization↑ with emergent functional codes; no human-authored curricula as training input). Only null claim is scale-free; everything else ships with scaling hypothesis + field test. Proposed cost guardrail (not law): ~1.2M tokens/sample kill-cap past which derivation signal drowns.
**Stats rules:** n≥8 for ignition claims, report seed-means + bimodality, bars labeled convenience, proxy 0.61 = moderate (rank only).
